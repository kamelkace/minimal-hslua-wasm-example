# A minimal compiling example of using hslua for a wasm project
This applies a few (poorly written) patches to Lua (as vendored into hslua) so that a parent project can be compiled with a [WASM GHC toolchain](https://gitlab.haskell.org/haskell-wasm/ghc-wasm-meta). It's just a proof of concept, and there aren't any tests.
